
# CodeTogether

Учебный проект для групповой онлайн-разработки
и совместного редактирования программного кода.

## Описание проекта

CodeTogether - веб-приложение, позволяющее
нескольким пользователям совместно работать
над одним программным кодом в реальном времени.

Проект разработан в рамках курсовой работы
на тему:

"Исследование инструментов для групповой
онлайн-разработки и совместного редактирования кода".

## Основные возможности

1. Создание общей комнаты для разработки.
2. Подключение нескольких участников.
3. Совместное редактирование программного кода.
4. Синхронизация изменений через WebSocket.
5. Отображение подключённых пользователей.
6. Контроль версий документа.
7. Обнаружение конфликтов редактирования.
8. Автоматическое обновление содержимого редактора.

## Используемые технологии

- Python - серверная часть.
- JavaScript - клиентская логика.
- HTML - структура интерфейса.
- CSS - оформление приложения.
- WebSocket - обмен данными в реальном времени.
- unittest - автоматизированное тестирование.

## Структура проекта

- server.py - сервер приложения.
- core.py - логика совместного редактирования.
- index.html - пользовательский интерфейс.
- style.css - оформление интерфейса.
- app.js - взаимодействие с сервером.
- test_core.py - модульные тесты.
- requirements.txt - зависимости проекта.
- README.md - документация.

## Инструкция по запуску

1. Установить Python.
2. Скачать проект с GitHub.
3. Открыть терминал в папке проекта.
4. Установить необходимые библиотеки:

```bash
python -m pip install -r requirements.txt
```

5. Запустить сервер:

```bash
python server.py
```

6. Открыть браузер и перейти по адресу:

http://127.0.0.1:8000

7. Открыть приложение в двух вкладках браузера.

8. Указать одинаковое название комнаты,
но разные имена пользователей.

9. Нажать кнопку "Подключиться".

10. Проверить совместное редактирование кода.

## Тестирование

Для проверки основных функций разработаны
20 автоматизированных модульных тестов.

Запуск тестирования:

```bash
python -m unittest test_core -v
```

Тесты проверяют:

- Создание комнаты.
- Подключение пользователя.
- Отключение пользователя.
- Проверку имени участника.
- Изменение программного кода.
- Увеличение номера версии.
- Обнаружение конфликтов.
- Проверку корректности входных данных.
- Ограничение размера документа.

## Ограничения

CodeTogether является учебным прототипом.

Приложение использует проверку версии документа,
но не реализует полноценное объединение
одновременных изменений по алгоритмам CRDT.

При конфликте пользователь получает актуальную
версию документа и должен повторить свою правку.

Данные хранятся в оперативной памяти сервера
и сбрасываются после его перезапуска.

Приложение предназначено для локального запуска
и не рассчитано на размещение в открытом интернете
без дополнительной настройки безопасности.
