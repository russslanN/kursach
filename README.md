# CodeTogether — учебный прототип группового редактирования кода

Проект к курсовой «Исследование инструментов для групповой онлайн-разработки и совместного редактирования кода».

## Запуск

```bash
python -m pip install -r requirements.txt
python server.py
```

Откройте `http://127.0.0.1:8000` в двух вкладках, укажите одинаковую комнату и разные имена. Изменения текста синхронизируются по WebSocket.

## Тесты

```bash
python -m unittest discover -s tests -v
```

## Ограничения

Это учебный прототип с контролем версий документа, а не полноценный промышленный редактор. Одновременные несовместимые правки могут приводить к уведомлению о конфликте и необходимости повторно внести изменение. Документы хранятся в памяти процесса, поэтому после перезапуска сервера состояние сбрасывается. Сервер привязан к localhost и не имеет авторизации, поэтому не предназначен для размещения в открытом интернете.
